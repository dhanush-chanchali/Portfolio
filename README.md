# 🚀 AI & Data Science Portfolio | Dhanush Chanchali

Welcome to the official repository for my personal academic and project portfolio. This single-page, responsive website showcases my work, technical expertise in **Machine Learning**, **Predictive Analytics**, and software development, alongside my academic background at **KL University**.

---

## ✨ Features
* 📱 **Fully Responsive Layout:** Optimized for desktops, tablets, and mobile devices with a clean slide-out menu.
* 🌙 **Modern Dark Aesthetic:** Clean, developer-centric slate and indigo theme built for readability.
* 🛠️ **Categorized Skills Grid:** Highlights core competencies across Programming Languages, AI/Data Science libraries, and Development Tools.
* 📊 **Interactive Project Cards:** Displays project overviews, tech stacks, and hyperlinked source repositories.
* 🔗 **Direct Professional Links:** Integrated hyperlinks to LinkedIn, GitHub, and direct email communication.

---

## 🛠️ Built With
* **HTML5** — Semantic structure and content organization.
* **CSS3** — Custom CSS Grid/Flexbox layouts, dark mode variables, and micro-animations.
* **JavaScript (Vanilla)** — Mobile menu navigation and interactive controls.
* **Font Awesome** — Vector icons for UI elements and technical skill badges.
